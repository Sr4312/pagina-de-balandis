# BALANDIS Energy Gel — brief

> Renombrado de AURA a BALANDIS el 12 Oct 2026. El sistema visual sigue el manual de marca AURA v1.0; el wordmark BALANDIS es un redibujo monolínea provisorio. Las fotos generadas (assets/img) llevan el nombre viejo impreso y están desconectadas hasta regenerarlas.

**Belief:** Con AURA elijo en un segundo y sigo en movimiento.
**Journey:** Producto primero — hero (sachets + franja) → el dato (30 g) → sabores (signature) → cuándo usarlo → cómo usarlo → con o sin cafeína → dónde conseguirlo (Tinta) → cierre "Energía clara."
**Signature move:** *La franja que sube* — una sola franja diagonal a 15° atraviesa la página llevando el dato clave. En la sección de sabores la sección se pinnea unos 3 viewports: el fondo pasa por las bases de cada sabor (Neutral → Citrus → Peach Mango), la franja barre en el tono intenso correspondiente y el sachet de cada sabor entra mientras el anterior sale. El elemento gráfico del manual se vuelve el motor del scroll.
**Energy curve:** Apertura fuerte, después sustancia — pins: hero (1 viewport), sabores (3 viewports); scrubs: contador 30 g, barrido de franja, reveals de secciones; static: cómo usarlo, puntos de venta, footer.
**Register:** El del manual — Jost Light/Regular para titulares, Barlow 400/500/600/700 para informar; paleta Tinta `#161616` / Blanco / Niebla `#EEEFF0` + tonos intenso/medio/base por sabor; ritmo de color Blanco-Niebla 50 % · sabores 30 % · Tinta 20 %; una sola sección en Tinta (dónde conseguirlo). Texto sobre color de sabor siempre en Tinta. Logo solo Tinta o blanco.
